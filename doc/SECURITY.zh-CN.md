# 安全模型

简体中文 | [English](SECURITY.md)

## 保护对象与信任假设

主要保护对象包括主机凭据与文件、载荷机密性和完整性、Guest 实例状态、虚拟机之间的隔离，
以及发布来源。主机操作系统、Hypervisor API、选定的 crosvm 构建、Guest 内核、启动链和
载荷验证器属于可信计算基；载荷及其输入可以不可信。可选设备端点会扩大攻击面，必须显式启用。

## 控制措施

- 硬件 CPU 与内存虚拟化将 Guest 执行与主机进程隔离。
- Microdroid 减少 Guest 服务，并在执行前验证载荷元数据。
- 启动计划枚举设备与主机桥接；未声明能力默认拒绝。
- 每实例工作目录避免不同工作负载共享可写磁盘。
- manifest 固定组件版本，发布产物应计算并校验哈希。

## 限制与加固

仅使用本仓库不等于部署已通过认证，也不能保证每个主机都有硬件信任根，更不能把调试或
未加密开发配置变成生产配置。请求的保护不可用时必须关闭失败。移除调试策略和 Guest Shell，
限制网络出站，主机桥接进程遵循最小权限，使用不可变基础镜像和私有覆盖层，并将签名材料与
构建机分离。完整 Android Guest 的攻击面大于 Microdroid 基线。

漏洞请按照仓库根目录[安全策略](../SECURITY.zh-CN.md)私下报告。
