# Troubleshooting

| Symptom | First check | Do not do |
| --- | --- | --- |
| Missing private binding or hash mismatch | Exact installed profile/closure and matching release index | Substitute placeholders or waive admission |
| Host library/module not found | Complete same-version recursive library closure and supported layout | Mix r14 DLLs or patch binary bytes |
| Guest not READY | Original Guest/controller logs and exact Host/Guest pair | Treat process creation as READY |
| GPU count zero | Matching graphics Guest, normal boot configuration and formal loader evidence | Treat a direct probe as formal loader success |
| Timeout/disconnect | Original task state, stable handle and exit/EOF evidence | Replay business or convert UNKNOWN to PASS |
| Permission denied | Distinguish tool policy, OS identity/ACL and product API failure | Change ACL/UAC/network or switch identity blindly |
| Garbled document | Read raw UTF-8 bytes; compare published response with source | Re-encode through a legacy console code page |

Preserve the first error and original evidence. A wrapper exception is not necessarily the underlying cause. Report platform, exact artifact hashes, command, exit/EOF status and redacted error categories; do not publish private paths or credentials. Historical Mac ext4 failure and disabled Windows independent CLI reconnect remain explicit limitations, not troubleshooting instructions to bypass checks.
